# AudioPlaybackConnector
**English** | [简体中文](https://github.com/ysc3839/AudioPlaybackConnector/blob/master/README.zh_CN.md)

Bluetooth audio playback (A2DP Sink) connector for Windows 10 2004+.

Microsoft added Bluetooth A2DP Sink to Windows 10 2004. However, a third-party app is required to manage connection.\
There is already an app can do this job. However it can't hide to notification area and it's not open-source.\
So I write this app, provide a simple, modern and open-source alternative.

# Usage
* Download and run AudioPlaybackConnector from [releases](https://github.com/ysc3839/AudioPlaybackConnector/releases).
* Add a bluetooth device in system bluetooth settings. You can right click AudioPlaybackConnector icon in notification area and select "Bluetooth Settings".
* Click AudioPlaybackConnector icon and select the device you want to connect.
* Enjoy!

# Changes in this fork (Win11 edition)
* **Fixes "connected but no sound" on the first connect**: after the first successful `OpenAsync()` the app silently disconnects and reconnects once to activate the A2DP audio endpoint (the manual "connect twice" workaround, automated). Can be disabled in the panel.
* **Auto reconnect**: unexpected disconnects are retried with 1s / 2s / 4s ... up to 30s exponential backoff; toggle in the tray menu or panel.
* **Reconnect button**: tray menu and connection panel both offer a one-click reconnect for all known devices.
* **Restore on start**: optional "Reconnect on next start" remembers the last devices.
* **Windows 11 UI**: left click the tray icon to open a rounded connection panel (device states, reconnect button, three toggles); tray menu and exit flyout use Win11 Fluent styling and follow the system light/dark theme. The system device picker is available via "Connect a device".
* Also fixes upstream never calling `LoadTranslateData()`, so bundled zh_CN / zh_TW translations now work, and adds translations for all new strings.
* Settings live in `AudioPlaybackConnector.json` next to the executable and stay compatible with older config files.

# Build
Requires Visual Studio 2022 with the "Desktop development with C++" workload and a Windows 11 SDK:

```powershell
nuget restore AudioPlaybackConnector.sln
msbuild AudioPlaybackConnector.sln /p:Configuration=Release /p:Platform=x64 /m
```

Translation resources are generated by `python translate/po2ymo.py` (standard library only) into `translate/generated/`. The GitHub Actions workflow in this repo restores packages, generates the resources and builds automatically.
